Section 1

What is Traversal?

Traversal means visiting every item, one at a time. In AP CSA you do it with a loop and an index.

Real-life analogyTaking attendance in a classroom. You must visit every student — skip one and your roll call is wrong.
int[] scores = {88, 92, 75, 98, 84};
// Standard for loop: start at index 0, stop before length
for (int i = 0; i < scores.length; i++) {
    System.out.println("Index " + i + " = " + scores[i]);
}
// Enhanced for loop: use when you don't need the index
for (int s : scores) {
    System.out.println(s);
}
const scores = [88, 92, 75, 98, 84];
// Same idea: visit index 0 up to length - 1
for (let i = 0; i < scores.length; i++) {
  console.log(`Index ${i} = ${scores[i]}`);
}
🤔 Why is traversal needed before solving most problems?
Almost every array problem (max, min, search, count, sort) needs to look at the data. Traversal is how you look at every element, so it is the foundation the other algorithms are built on.
Section 2

What is Selection?

Selection means choosing a value that satisfies a rule while you traverse, such as "the biggest one so far".

Real-life analogyFinding the tallest basketball player. Walk down the line and remember the tallest you've seen so far.
// Keep a "best so far" and challenge it with each new value
int best = heights[0];
for (int i = 1; i < heights.length; i++) {
    if (heights[i] > best) {   // the rule: taller wins
        best = heights[i];
    }
}
🤔 What happens when a larger value is found?
The "best so far" variable is replaced by the larger value. If nothing larger shows up, the best stays the same.
Section 3

Find the Maximum

Start by assuming the first element is the max, then compare it with every other element.

Real-life analogyStudent of the Month: the student with the highest grade wins.
public static int findMax(int[] arr) {
    int max = arr[0];                 // assume first is biggest
    for (int i = 1; i < arr.length; i++) {
        if (arr[i] > max) {
            max = arr[i];
        }
    }
    return max;
}
function findMax(arr) {
  let max = arr[0];
  for (let i = 1; i < arr.length; i++) {
    if (arr[i] > max) max = arr[i];
  }
  return max;
}
Section 4

Find the Minimum

Same model as maximum — just flip the comparison from > to <.

Real-life analogyFinding the cheapest item in a store.
int min = prices[0];
for (int i = 1; i < prices.length; i++) {
    if (prices[i] < min) {   // only this symbol changed!
        min = prices[i];
    }
}
Section 5

Linear Search

Linear Search checks every item one by one until it finds the target or runs out of items. The array does not need to be sorted.

Real-life analogySearching for earbuds inside a backpack — pull things out one at a time.
public static int linearSearch(int[] arr, int target) {
    for (int i = 0; i < arr.length; i++) {
        if (arr[i] == target) {
            return i;      // found: return the index
        }
    }
    return -1;             // not found
}
function linearSearch(arr, target) {
  for (let i = 0; i < arr.length; i++) {
    if (arr[i] === target) return i;
  }
  return -1;
}
Section 6

Binary Search

Binary Search cuts the search space in half each step by checking the middle element.

Real-life analogyFinding a word in a dictionary: open the middle, decide which half the word is in, repeat.
public static int binarySearch(int[] arr, int target) {
    int low = 0, high = arr.length - 1;
    while (low <= high) {
        int mid = (low + high) / 2;   // integer division
        if (arr[mid] == target) return mid;
        else if (arr[mid] < target) low = mid + 1;   // go right
        else high = mid - 1;                          // go left
    }
    return -1;
}
function binarySearch(arr, target) {
  let low = 0, high = arr.length - 1;
  while (low <= high) {
    const mid = Math.floor((low + high) / 2);
    if (arr[mid] === target) return mid;
    if (arr[mid] < target) low = mid + 1;
    else high = mid - 1;
  }
  return -1;
}
🤔 Why must the array already be sorted?
Binary Search throws away half the array based on one comparison. That only works if every value on one side is guaranteed to be smaller and every value on the other side larger — i.e. sorted order.
Section 7

Selection Sort & Nested Loops

Selection Sort repeatedly finds the smallest value in the unsorted part and swaps it into its correct location. The outer loop picks the position; the inner loop searches for the minimum — that's a nested loop.

Real-life analogyOrganizing playing cards in your hand: find the lowest card, put it first, repeat with the rest.
public static void selectionSort(int[] arr) {
    for (int i = 0; i < arr.length - 1; i++) {        // outer: which position to fill
        int minIndex = i;
        for (int j = i + 1; j < arr.length; j++) {    // inner: find the smallest
            if (arr[j] < arr[minIndex]) {
                minIndex = j;
            }
        }
        int temp = arr[i];                              // swap into place
        arr[i] = arr[minIndex];
        arr[minIndex] = temp;
    }
}
function selectionSort(arr) {
  for (let i = 0; i < arr.length - 1; i++) {
    let minIndex = i;
    for (let j = i + 1; j < arr.length; j++) {
      if (arr[j] < arr[minIndex]) minIndex = j;
    }
    [arr[i], arr[minIndex]] = [arr[minIndex], arr[i]];
  }
}
