A

Java · CodeHS

AP Computer Science A

Students are working in CodeHS Unit 2: Algorithms, Boolean Expressions, and If Statements.

Weekly standards

College Board AP Computer Science A · Unit 2: Selection and Iteration

Students will:

  • Develop and analyze algorithms using sequencing, selection, and repetition.
  • Evaluate Boolean expressions that produce true or false values.
  • Use if statements and nested if statements to control program behavior.
  • Trace, test, and debug Java programs involving selection.
  • Apply computational thinking to solve programming problems.

Topics

  • 2.1 Algorithms with Selection and Repetition
  • 2.2 Boolean Expressions
  • 2.3 If Statements
  • 2.4 Nested If Statements

Weekly learning targets

Students can:

  • Explain how algorithms use selection and repetition.
  • Evaluate Boolean expressions.
  • Predict program output.
  • Create decisions using if statements.
  • Trace nested conditional structures.

Essential question

How do programmers use logical decisions to control software behavior?

Daily activities

Tuesday · Unit 2.1

Algorithms with Selection and Repetition

  • Open CodeHS and complete the assigned lesson.
  • Review examples and update the journal.

Wednesday · Unit 2.2

Boolean Expressions

  • Complete the lesson.
  • Practice Boolean reasoning and update the journal.

Thursday · Unit 2.3

If Statements

  • Complete the lesson.
  • Practice examples and update the journal.

Friday

Continue Unit 2 progress

  • Practice concepts.
  • Complete the reflection.

Success criteria

  • Complete Unit 2 lessons.
  • Practice Java daily.
  • Update the journal.
  • Demonstrate understanding of Boolean expressions.
  • Demonstrate conditional reasoning.

Java motivation

if (studyInClass && practiceEveryDay >= 35) {
    passExam();
} else {
    runSurvivalTraining();
}

Learning platforms

  • CodeHS Required lessons
  • CodingBat Java Practice
  • AP CSA Unit 1 Survival Camp Additional practice

For the substitute

Students should complete the assigned Unit 2 lesson, practice Java, and keep their learning journal up to date. Encourage them to trace conditions before predicting a result.

B

Research · Data technology

AP Computer Science Principles

Big Idea 2 · Data Technology Research Symposium

Weekly standards

College Board AP Computer Science Principles · Big Idea 2: Data

Students will:

  • Explain how data can be represented digitally.
  • Analyze how data is collected, stored, compressed, secured, and processed.
  • Investigate innovations that depend on data.
  • Evaluate the impact of data on society, careers, and industries.
  • Communicate technical information through research and presentations.

Big Idea 2 topics

  • Binary Numbers
  • Data Compression
  • Extracting Information from Data
  • Using Programs with Data

Weekly learning targets

Students can:

  • Explain key data technologies.
  • Research historical contributors and innovations.
  • Explain algorithms and technical processes.
  • Connect data technologies to careers.
  • Analyze ethical concerns and future trends.

Essential question

How has the development of data technologies changed society and modern industries?

Daily activities

Tuesday · Research & Planning

  • Assign team roles.
  • Gather sources and create an outline.

Wednesday · Research & Development

  • Research history, inventors, algorithms, applications, and careers.
  • Goal: presentation is 50% complete.

Thursday · Presentation Development

  • Develop visuals and speaker notes.
  • Add references and an audience activity.

Friday · Review & Rehearsal

  • Check accuracy, citations, and timing.
  • Rehearse professional presentation expectations.

Success criteria

  • Research completed.
  • Presentation created.
  • AMA citations included.
  • Team participation completed.
  • Rehearsal completed.

C

HTML · CSS · CodeHS Sandbox

Intro to Software Technology / CSP

Course project: Career Exploration Website

Weekly standards

Georgia CTAE Introduction to Software Technology

  • IT-IST-1.3 Exhibit critical thinking and problem-solving skills to locate, analyze, and apply information in career planning and employment situations.
  • IT-IST-1.5 Apply the appropriate skill sets to be productive in a changing technological workplace and work independently or collaboratively.
  • IT-IST-3.1 Develop technical reading and writing skills to follow instructions.
  • IT-IST-3.3 Research specific IT careers, including post-secondary education options, credentials, required job skills, salaries, and work environments.

Weekly learning targets

Students can:

  • Research technology careers.
  • Explain required education and certifications.
  • Analyze workplace responsibilities.
  • Build a professional website using HTML and CSS.
  • Organize and communicate information effectively.
  • Cite sources appropriately.

Essential question

How can websites be used to communicate information about technology careers?

Daily activities

Tuesday

  • Choose a career.
  • Create a Sandbox project, research the topic, and create the homepage.

Wednesday

  • Add the overview, history, and industry leaders.
  • Begin CSS styling.

Thursday

  • Add salary information, future outlook, and related careers.
  • Complete CSS styling.

Friday

  • Complete a final review.
  • Check links and images, then submit the project.

Career categories

  • Software careers
  • Cybersecurity careers
  • Data & AI careers
  • Networking & cloud careers
  • Game development careers

Required website sections

  • Career overview
  • Career history
  • Industry leaders
  • Skills needed
  • Education & certifications
  • Salary information
  • Future outlook
  • Related careers
  • Sources

Early finishers · CodeHS Unit 10

After their website work is complete, students may begin Unit 10 topics: variables, user input, functions, graphics, and animations.

Helpful resources

  • W3Schools
  • CSS-Tricks
  • CodePen
  • Google Fonts
  • Coolors
  • Color Hunt

Learning platform

  • CodeHS Sandbox HTML & CSS

Students build the project using HTML and CSS in the Sandbox.

For the substitute

Check that students select a technology career and build the required sections. Students should use credible sources and include citations; they should test links and images before submitting.

D

Unity · Iterative development

Game Design & Simulation

Continue Unity development projects, apply teacher feedback, and work through Unity Junior Programmer Module 3.

Weekly standards

Georgia Game Design: Animation & Simulation

  • GDAS2.2 Identify and apply the primary steps in the game design process including conceptualizing, prototyping, testing, and analyzing.
  • GDAS2.6 Plan and organize tasks required to complete a game development project.
  • GDAS3.1 Apply script binding, components, and prefabricated objects within game projects.
  • GDAS3.2 Determine appropriate programming and scripting techniques to create game mechanics, user interface elements, and gameplay systems.
  • GDAS3.3 Demonstrate an understanding of conditional programming statements used in game development.
  • GDAS3.8 Demonstrate an understanding of object-oriented programming concepts within game projects.

Weekly learning targets

Students can:

  • Improve an existing Unity project using feedback.
  • Refine scenes, game objects, and camera systems.
  • Apply the game development cycle: design, test, analyze, and improve.
  • Continue progress in Unity Junior Programmer Module 3.
  • Demonstrate understanding of Unity components and game objects.
  • Test and debug game functionality.
  • Document development decisions and future goals.

Essential question

How do game developers use testing, feedback, and iteration to improve games?

Daily activities

Tuesday

  • Review feedback.
  • Improve the scene and continue development.

Wednesday

  • Continue project work.
  • Continue Unity Junior Programmer Module 3.

Thursday

  • Test the project.
  • Refine the camera and scene.

Friday

  • Document work and reflect.
  • Plan the next development goal.

Success criteria

  • Review teacher feedback.
  • Continue development.
  • Complete scene improvements.
  • Complete camera improvements.
  • Update the journal.

Learning platforms

  • Unity Development platform
  • Unity Learn Junior Programmer Module 3

For the substitute

Students should use their own project feedback, make and test improvements, and document their progress. If a student is not working in Unity, direct them to the assigned Unity Junior Programmer Module 3 work.

For every class

Student expectations

  • Work independently and follow the directions for your course.
  • Use the required learning platform and assigned resources.
  • Stay on task and use class time productively.
  • Ask the substitute for help if you cannot access your assigned work.
  • Save your work and submit it as directed by your teacher.
  • Leave your workspace ready for the next class.
