# AP CSP Python Survival Camp

An interactive, self-paced Python learning site for AP Computer Science Principles students. The site is implemented with plain HTML, CSS, and JavaScript.

## Open the site

Open [PythonCSbootcamp.html](./PythonCSbootcamp.html) in a browser. It loads `style.css` and `script.js` from this same folder; no package installation or build step is required.

## Build prompt

> Build a responsive, beginner-friendly AP Computer Science Principles Python learning website called **Python Survival Camp**. Use plain HTML, CSS, and JavaScript without external frameworks or dependencies. Organize the learning experience into nine interactive modules covering Python expression order, arithmetic including floor division (`//`) and remainder (`%`), variables, Boolean logic, conditionals, loops, debugging, and assessment practice. Teach students to predict, explain, visualize, and verify how code runs. Include a Python Thinking Machine that evaluates expressions step by step and explains the reasoning, as well as interactive questions with feedback and explanations. Track answers, progress, XP, ranks, badges, and streaks in the browser so progress persists between visits. Provide a clear camp-themed home page and module navigation, accessible controls, and a layout that works on desktop and mobile.

## Files

- `PythonCSbootcamp.html` — page structure and document metadata
- `style.css` — responsive camp-themed visual design
- `script.js` — modules, interactive activities, Python Thinking Machine, and browser-saved progress
